# Compiled Agent Metadata Template

```yaml
---
toolkit_name: AI Agent Skills Toolkit
toolkit_version:
toolkit_pin:
compiled_status: approved|review
compiled_at: deterministic-not-recorded
source_commit:
input_digest: sha256:
input_digest_scope: canonical-agent-inputs-v1
compiler_digest: sha256:
source_agent:
compiler: scripts/compile-agents.mjs
registry_input: registries/agents.registry.json
source_profile_refs: []
source_method_refs: []
compile_contract_version:
---
```

Metadata must be generated by the reviewed deterministic compiler. `source_commit` is the latest commit touching fixed canonical agent/compiler paths, not the current `HEAD` and never a caller-supplied override. `input_digest` and `compiler_digest` gate exact content integrity. Approved registry agents compile as `approved` only when the source agent passes source-quality and parity validation; draft or unapproved agents compile as `review`. Do not mechanically restamp compiled agents without regenerated provenance and review evidence.
